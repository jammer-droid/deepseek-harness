# 최적화 UI 초안

기존 Studio 서비스 탭·DetailLayout·공용 부품·스타일을 유지한 단일 목업이다. 실제 호출, DSH 설정 변경, 저장, 프리셋 파일 생성은 수행하지 않는다. 모든 편집 상태는 메모리에만 존재하며 새로고침하면 초기화된다.

## 확인

```sh
npm --prefix studio run web
```

출력된 토큰 포함 URL에서 DSH Studio → 최적화를 선택한다.

- 서브에이전트 설정: 예시 Researcher/Reviewer 선택, 추가, 고유 설정 편집, 항목별 공통 상속/개별 재정의.
- 프롬프트·도구: 공통 시스템 지침과 도구 정책 편집.
- 작업 편의: spill·대기·batch 예시 설정.
- 프리셋 내보내기: 현재 초안 JSON 확인. 실제 내보내기는 비활성.

공통 spill 값을 바꾸고 상속 중인 Researcher와 개별 값이 있는 Reviewer의 최종 값을 비교한다. Reviewer를 공통 상속으로 되돌리면 새 공통 값이 표시되어야 한다. 개별 설정에서 사용 안 함을 선택하면 공통 값과 독립적으로 표시된다.

재정의는 현재 단순 대체 방식이다. 지침 추가/교체·복원, 자체 도구 설명 편집, 도구별 세밀한 선택은 후속 UI 범위다. 모델과 도구 묶음은 예시이며 런타임 카탈로그가 아니다. 개별 spill·대기 적용과 권한 강제 등 호환성은 검증하지 않았다.

기존 Studio 타입 검사·빌드·11개 회귀 검사를 실행했다. 실제 브라우저의 라이트·다크·좁은 화면 시각 검증은 별도 사용자 확인이 필요하다.
