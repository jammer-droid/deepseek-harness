# 최적화 UI 초안

> **대체된 초기 목업:** 현재 구현이나 진행 중인 계획이 아니다. 당시 선택 흐름과 검사 기록을 보존한다. 후속 개선은 [UI·UX 백로그](../../plans/ui-ux-backlog.md), 현재 기능은 [문서 목차](../../README.md)를 따른다.

## 배치와 선택

상단에 프롬프트 조립, 하단에 도구 선택을 둔다. 두 영역 모두 공용 SelectionTransfer로 사용 가능/선택됨 투 컬럼과 추가·제외 동작을 제공한다. 설명은 원문 전체를 읽기 전용 카드로 표시한다.

프롬프트 제공자는 기준 프리셋의 선언에서 persona, agent-instructions, time-context를 명시적으로 분류한다. 모든 DSH 플러그인을 자동 분류하는 API는 없으므로 지원 범위를 확장할 때 명시적인 검토가 필요하다. 전역 공통 지침은 선택 대상으로 노출하지 않으며 항상 조립에 참여한다. persona complete 설정은 Studio 추가 지침까지 제거할 수 있다.

도구 수집은 기존 전역·프리셋 schemas/assembly 합집합을 유지한다. 등록된 커스텀 도구도 표시된다. 미등록 read_batch를 임의로 추가하지 않는다. 도구 이름 선택만으로 제공자를 설치하지 않으며, 현재 미리보기는 선택한 기준 프리셋에서 실제 공급할 수 있는 도구만 허용한다. 여러 프리셋의 도구 제공자 구성 자동 병합은 아직 지원하지 않는다.

## 실제 조립 미리보기

Studio Host가 읽은 기준 프리셋 선언에서 선택하지 않은 관리 대상 프롬프트 플러그인만 제거하고 임시 프리셋으로 등록한다. 선택하지 않은 도구도 제공자 자체는 기준 구성에 남을 수 있다. 임시 프리셋 scope의 자식 scope에서 도구 allow 제한을 적용하고 Studio 추가 지침을 persona suffix 다음 순서에 등록한다. 공개 systemPrompt.assemble과 renderPrompt를 호출하여 반환 순서를 그대로 표시한다. Studio 입력은 interpolate:false로 리터럴 처리한다.

미리보기 모델명은 모델 호출 없이 {{model}} 변수 값을 제공한다. 미입력 변수 참조는 렌더러 오류를 그대로 보여주며 임의로 추정하지 않는다. 도구 스키마와 런타임 컨텍스트는 시스템 프롬프트와 구분해 표시한다. PTC는 런타임의 run_code 표시 규칙을 유지한다. 미리보기는 세션 없는 현재 스냅샷이며 실제 실행 시의 작업 경로·세션 사실과 같다고 보장하지 않는다.

미리보기는 모델이나 세션을 만들지 않지만 실제 플러그인 초기화는 실행한다. 임시 프리셋이 작업 중 목록에 잠깐 나타날 수 있다. 자식 scope, lease, 임시 등록은 중첩 finally로 정리한다. 기존 프리셋 선언과 프로필 파일은 쓰지 않는다. 설정 변경 후 이전 결과는 오래된 결과로 표시하고 재실행을 요구한다.

## 검증과 한계

Studio 타입 검사·빌드·테스트 16/16와 공백 검사 통과. 수정하지 않은 DSH 0.2.0-rc.2의 격리 프로필에 패키징한 Studio만 설치하여 실제 조립 RPC를 검증했다. scripts/check-preview-runtime.mjs에 토큰 포함 미리보기 URL을 전달하면 추가 지침 반영, read/grep/glob 제한, 빈 도구 선택, 실패·성공 후 임시 프리셋 제거를 다시 검사한다. Chrome에서도 Studio 미리보기 RPC 성공을 확인했다. UI 시각 확인은 사용자가 담당한다.

개발 디렉터리의 절대 경로 플러그인 주입은 사용하지 않는다. 이 방식은 개발 의존성의 dsh-scope와 런타임 사본이 분리되어 tools.restrict가 scope를 인식하지 못했다. npm run web은 매번 새 경로의 tarball을 만들어 Studio 내부 .dsh-home 격리 프로필에 설치한다. 새 경로는 같은 버전 tarball의 캐시 재사용을 방지한다. DSH 본체·루트 lockfile·기존 사용자 프로필은 변경하지 않는다. 설치 시 peer dependency 경고가 남으며 다른 DSH 버전은 미검증이다.

세션 없는 미리보기의 cwd 변수는 Studio 서버의 process.cwd()다. 선택한 세션의 작업 경로가 아니다. 전역 persona가 model 변수를 요구할 수 있으므로 미리보기 모델명에 값을 입력해야 한다. 값이 없으면 렌더러 오류를 그대로 표시한다.
