# 마스터 Config 편집 진행 기록

기준 커밋: `d0cdc6ea3d`. 변경 범위는 Studio 전용. 대상은 수정하지 않은 DSH `0.2.0-rc.2`.

## S1 — 마스터 및 Studio 추가 제공자

명시적 기본 구성으로 28개 도구를 활성화한다. Studio 추가 제공자 편집에서 설치된 패키지의 JSON 구성 목록을 등록·저장하고 마스터를 갱신한다. 신규 도구 코드를 작성하거나 패키지를 설치하는 기능은 아니다. 임시 프리셋으로 활성화를 검증한 뒤 교체하며 실패하면 기존 구성을 복구한다. 파일 저장은 원자적 교체 방식이다. 사용자 프리셋의 적용 스냅샷은 자동으로 바꾸지 않는다.

추가 구성은 신뢰하는 코드만 사용해야 한다. 검증용 활성화도 플러그인 코드를 실행하며 외부 부작용까지 되돌려 주지는 않는다. 설정은 profile의 studio-data/master-extensions.json에 평문 저장하며 추가 제공자 편집 RPC는 그 값을 반환한다. 일반 카탈로그에는 추가 구성의 원시 Config를 싣지 않는다.

호환성 경계:
- schedule은 이 rc.2 Host에 서비스가 없어 제외한다. 별도 Host singleton을 프리셋에 임의 설치하지 않는다.
- minimal의 persistent shell은 native bash와 이름이 겹치는 대안이다. 합집합에 넣지 않는다.
- PTC는 agent-tool-presentation의 실행 노출 모드이며 별도 도구 제공자 모음이 아니다. 현재 기본 마스터는 native 유지. PTC 프리셋 전체 호환은 완료 주장 범위 밖이다.
- 추가 제공자가 기존과 같은 도구 이름을 등록하는 경우의 의미적 충돌까지 정적으로 검증하지 않는다.

## S2 — Config 재정의

마스터 구성 항목 경로에 공개 Config 스키마를 연결한다. 객체는 재귀 병합, 배열·스칼라는 교체하고 false/0/빈 문자열을 보존한다. 알 수 없는 항목과 위험 키는 거부한다. 원래 플러그인 활성화 검증 결과를 확인한다. 실제 persona Config 재정의가 미리보기 프롬프트를 바꾸는 것을 검증했다.

## S3 — 구조 기반 UI

플러그인 단위 투 컬럼 선택, 중첩 객체 폼, 로컬 참조, 숫자·문자열·불리언·enum, 필드별 재정의 해제를 제공한다. 실제 rc.2의 Loader 표현식 anyOf 및 nullable 래퍼를 해석해 일반 값은 항목별 폼으로 표시한다. 스키마 기본값은 표시만 하고 재정의로 저장하지 않는다. Config의 자유 JSON 편집은 제거했으며 배열·복합 타입 등 미지원 구조는 안내만 표시하고 기존 값을 보존한다. shell/fs/spill Config는 기본 선택하되 빈 override로 유지한다. Spill은 기본 미설정이므로 추가 제한을 활성화하지 않는다.

추가 도구 제공자는 프롬프트·도구 탭에 배치했다. 제공자 등록용 JSON은 유지하며 id/name/config 작성법, subagent 예시, 전체 목록 교체·삭제 및 의존성·도구 이름 충돌 주의사항을 안내한다.

Spill의 공개 필드는 maxInlineTokens이다. scope의 추가 정책이므로 Host 제한을 해제/확대할 수 없으며, 매우 작은 예산 등에서는 원본이 유지될 수 있다. read_batch는 설치된 실험 플러그인 도구이고 공개 Config가 없어 이 폼에 가짜 필드를 제공하지 않는다. 이전 execution 어댑터는 기존 저장 요청 호환용으로 남긴다.

## S4 — 검증

- Studio 44개 테스트, 타입 검사, 빌드 통과.
- 수정하지 않은 rc.2에 패키징해 격리 19388로 배포. 사용자 앱 19387 변경 없음.
- `scripts/check-master-runtime.mjs`: 28개 도구, 마스터 읽기 전용, 스키마 오류 없음, Config 포함 파생 프리셋 preview/save/apply/delete 성공.
- persona Config가 실제 조립 프롬프트에 반영됨. 잘못된 fs readLimit=-1 거부.
- 없는 제공자 추가 실패 후 마스터 유지. 설치된 subagent 제공자를 studio_extra_agent 이름으로 추가해 마스터 조회 및 파생 preview 성공. 테스트 후 원래 추가 구성 복원.
- 실제 신규 모델 세션에서 도구를 실행하는 검증, Spill 출력 파일 효과, 프로세스 재시작 후 마스터 복원은 미실행. 저장소 재개방 지속성은 단위 테스트로 확인.
- 실화면 라이트/다크/좁은 폭 검증은 사용자 확인 항목. DOM 상호작용 테스트는 통과.

최종 검증 독립 패키지: `dist/preview-1791888986199/local-dsh-studio-0.1.1.tgz`. 제공자 탭 이동·가이드와 Config 자유 JSON 편집 제거를 포함한다.

기존 catalog-runtime-verification 및 master-preset 문서의 standard 복사/전체 Loader 스키마 나열은 이전 단계 이력이다. 현재 계약은 이 문서를 따른다.
