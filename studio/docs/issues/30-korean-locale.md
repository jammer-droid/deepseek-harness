# #30 DSH 전체 한국어 번역

## 요약

DSH 화면 문구 전체를 한국어로 제공한다. Studio는 이미 `ctx.locale.addLanguage({ id: 'ko', fallback: 'en' })`로 한국어를 추가해 두었으므로, DSH 각 네임스페이스에 `ctx.locale.register(ns, 'ko', dict)`로 한국어 사전을 등록한다. 번역 작업은 별도 세션에서 스킬로 진행하고, 문장마다 `judge` 도구로 검수해 통과하면 다음으로 넘어간다.

- GitHub 이슈: [#30](https://github.com/jammer-droid/deepseek-harness/issues/30)
- 기준 브랜치·시작 커밋: `studio/feat/workflow` @ `b288fc95fa`
- 대상 DSH: `0.2.0-rc.2`. 본체 수정 없음
- 관련: 기존 스킬 `studio-ko-locale-review`(Pixie 문구 전용), `studio-pixie-hook-guide`, `judge` 도구(#27)

## 범위

**포함**

- 번역 스킬: `studio-pixie-hook-guide`를 이용해 만든다. 입력은 네임스페이스의 영어·중국어 원문, 출력은 한국어 사전. 문장마다 `judge`로 충실도·자연스러움을 판정하고 기준 미달이면 고쳐서 다시 판정한다.
- Studio 안의 사전: 네임스페이스별 `ko` 사전 파일과 등록 코드. 원문 키가 바뀌면 빠진 키를 찾는 검사.
- 번역할 수 없는 부분 목록(데스크톱 네이티브 메뉴, 사전을 거치지 않는 코드 문구).

**제외**

- DSH 본체 사전 파일 수정, 업스트림 기여
- 문서(README 등) 번역

## 결정

- **D1 원문 수집:** 미결정. 추천: 대상 버전(rc.2) 설치본의 배포 패키지에서 네임스페이스·키·en 원문을 추출하는 Studio 스크립트. workspace 소스는 버전이 다를 수 있다.
- **D2 검수 기준:** 미결정. 추천: `judge` bool 충실도 ≥ 0.8, score 자연스러움 기준은 #27 실사용 기록(같은 문구 재판정 시 흔들림)을 고려해 S2에서 정한다.
- **D3 진행 단위:** 네임스페이스 하나를 한 작업 단위로 한다. 대상 버전의 클라이언트 네임스페이스는 30여 개다(workspace 기준, rc.2에서 확인 필요).
- **D4 용어집:** 미결정. 추천: 세션·프리셋·게이트 등 공통 용어를 먼저 정해 스킬에 넣는다.
