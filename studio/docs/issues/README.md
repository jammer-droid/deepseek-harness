# Studio 이슈 명세

## 요약

이슈별 결정과 구현 단계는 이 디렉터리에 누적한다. 작성·검증·완료 절차는 [Studio 이슈 작업 절차](../issue-workflow.md)를 따른다. 진행 상태는 GitHub 이슈와 각 명세를 확인한다.

## 명세 목록

아직 작성된 이슈별 명세는 없다. 첫 대상은 [#15 지침 컴포넌트 초안 편집·저장](https://github.com/jammer-droid/deepseek-harness/issues/15)이다. 작업 브랜치는 `studio/workflow-15-draft`, 기준 브랜치는 `studio-general`, 시작 커밋은 문서 기획을 포함한 해당 작업 브랜치의 분기점이다. #15 완료 후 검증을 거쳐 기준 브랜치로 로컬 통합하는 것이 승인된 범위이며 푸시는 포함하지 않는다. 명세 작성 시 이 작업 정보를 해당 문서로 옮기고 색인에는 링크만 유지한다.
