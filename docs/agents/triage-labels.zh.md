# 分流标签

[English](triage-labels.md) | 中文

当工程 skill 指定规范分流角色时，使用以下跟踪器标签。

| 角色 | 跟踪器标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者提供信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 agent（智能体）自主实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

这些标签补充仓库现有的 PR（Pull Request）分类和原生 Issue Type 规则，不替代它们。

编辑跟踪器标签列可更改映射。
