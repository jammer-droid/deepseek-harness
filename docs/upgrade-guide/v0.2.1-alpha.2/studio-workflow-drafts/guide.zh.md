# Studio 工作流草稿存储

[English](guide.md) | 中文

## 变更

Studio 工作流草稿使用文档版本 2，包含稳定的组件实例 ID、系统配置和端口连接。已有草稿无需更改存储域版本即可读取。读取旧草稿时会在内存中规范化，下次显式保存时写入新文档格式。旧版 Studio 不支持该格式。

保存现在接受结构有效但存在配置错误的草稿，包括缺少系统和字段值无效的情况。已保存的草稿不一定有效、已应用或可执行。配置验证单独报告这些问题。

## 迁移

请同时更新运行时和 Studio 包。本版本 Studio 需要 api-remotes 的 `remoteEventContributions` Host 服务来实时接收目录通知；仅在旧运行时安装 Studio 包会导致所需服务不可用。

1. 如果可能需要回退到旧版本，请在使用新构建前备份已配置的 Studio 工作流草稿存储。保存版本 2 草稿后，不要覆盖该备份。
2. 在 Studio 中打开已有草稿，检查名称、组件顺序和保留的设置。注册缺失或版本不匹配的条目仍然可见，但为只读状态；不要通过删除条目来恢复可用性。
3. 显式保存以持久化规范化后的文档。单独解决配置诊断。配置验证通过不代表模型、权限或执行支持已经确认。
4. 降级时应恢复升级前的备份，不要用旧构建打开版本 2 记录。不支持自动降级或组件版本转换。
